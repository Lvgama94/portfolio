Python e SQL Server

Base de dados integrada

A fundação de todos os painéis: ETL em Python e modelo estrela no SQL Server.

O problema

Painel bom começa com dado confiável. Os arquivos chegam dos sistemas com duplicidades, cadastros repetidos, datas em dois formatos e números como texto.

Garantias

  • 11 testes automáticos depois de cada carga: nenhuma linha perdida, nota igual a título, receita da DRE igual às vendas, estoque nunca negativo
  • ~20 s para recriar o banco inteiro do zero

SELECT faixa_de_clientes,
       SUM(faturamento) AS faturamento,
       SUM(faturamento)
         / SUM(SUM(faturamento)) OVER ()
         AS pct_do_faturamento
FROM quintos
GROUP BY quinto;  -- 20% maiores: 73,4%
